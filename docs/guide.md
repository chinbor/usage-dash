# usage-dash 操作说明

按使用场景讲 usage-dash 怎么装、怎么看、怎么改。内部怎么实现见 [整体设计](design.md)。

## 1. 安装与更新

需要 Claude Code 2.1.275 或更高版本。

**安装**，三种方式任选：

- 终端会话里：`/plugin install usage-dash --marketplace chinbor/usage-dash`
- shell 里：`claude plugin install usage-dash --marketplace chinbor/usage-dash`
- 桌面版：点输入框旁的 + → Plugins → Add marketplace，填 `chinbor/usage-dash`，再 Add plugin。

装好后新开一个会话，输入框上方就会出现横条。第一次运行会生成配置文件 `~/.claude/usage-dash.json`，默认只有 Claude 和 Codex 两个数据源。

**更新**：`claude plugin update usage-dash@<marketplace 名>`，之后新开的会话用新版本。当前会话要用新版本，执行 `/reload-plugins`。

**卸载**：`claude plugin uninstall usage-dash`。

## 2. 看懂横条

### 折叠时（默认）

一行，只说需要注意的事：

| 显示 | 含义 |
| --- | --- |
| `▲ 3 项告警` | 有 3 个额度窗口低于提醒线 |
| `DeepSeek · 余额 ¥0.28` | 一条告警：平台 · 窗口 · 剩余 |
| `+2` | 还有 2 条告警没放下，展开看 |
| 右侧叠起的小图标 + `正常` | 这些平台额度充足 |
| 灰色小图标 + `异常` | 这些平台读取失败 |
| `● 全部充足` | 没有告警 |
| `○ N 项异常` | 没有告警，但有平台读不到 |

颜色：红色告急（剩余低于提醒线），黄色偏紧（低于提醒线的两倍），绿色充足。

### 展开后

点 **详情 ▾** 展开，每个平台一张卡片：

- 左边圆环是这个平台最紧的那个窗口的剩余百分比。
- 右边每个时间窗口一格：剩余、进度条、已用次数、多久后重置。窗口太多时合并成“+N 个窗口 · 最低 X%”。
- 平台多时分页显示，用 **收起** 左边的 **‹ 1/2 ›** 翻页，到最后一页再按 › 回到第一页。
- 点 **收起 ▴** 折叠。

### 附注的含义

| 附注 | 含义 |
| --- | --- |
| `12 分钟前的读数` | 这份数据不是刚读到的。Claude 额度只在回复后更新；新会话刚打开时显示的是上一个会话的读数 |
| `读取超时，下一轮再试` | 这个平台 20 秒内没响应，下次刷新再读 |
| `……，显示上次读数` | 这次读取失败，先显示上次成功的数据 |
| `本地记录 Nh 前` | Codex 实时读取失败，用的是本地会话记录 |

### 弹出提示

某个窗口刚降到告急时会弹一次提示，多个同时降到告急就合成一条。恢复到提醒线以上之前，不会重复提醒。

## 3. 设置面板

输入 `/usage-dash`（不带参数）打开设置面板。面板里的改动直接写回配置文件，横条随即刷新。顶部三个标签切换页面。

### 数据源页

最上面一行汇总：几个启用、几个停用、几项额度告警。下面每个数据源一张卡片：

- **状态徽标**：`● 充足` / `▲ 偏紧` / `▲ 告急` / `○ 未配置` / `○ 读取失败` / `已停用` / `读取中…`。卡片边框颜色跟着变。
- **一行读数**：各窗口的剩余；未配置时写明缺什么（比如“缺少环境变量 DEEPSEEK_API_KEY”）。
- **停用 / 启用**：停用只是暂时不在横条里显示，配置保留，随时可以再启用。适合退订了但可能回来的平台。
- **删除**：点了先出现确认行“确定删除……？会从配置文件里移除。”，再点 **删除** 才真的删，点 **取消** 放弃。
- **提醒**：这个平台单独的提醒线，可选“跟随全局”或 10% / 20% / 30% / 50%。DeepSeek 按余额提醒，这里显示余额阈值，要改就跟 Claude 说（见第 5 节）。
- 最下面一行小字是这个源的 id 和类型，命令和 Claude 改配置时用 id 指定它。

### 添加数据源页

每种类型一张卡片，写明显示什么、需要准备什么。已经加过的标“✓ 已添加 N 个”。

点 **添加**（加过的显示 **再加一个**）就按模板加入配置，并提示需要准备什么。需要环境变量的，设好变量后横条里会自动出现数据，不用重启。

### 显示与提醒页

| 设置 | 选项 | 说明 |
| --- | --- | --- |
| 显示在哪里 | 输入框上方的横条（推荐）/ 状态栏 / 不显示 | 状态栏只在有告警时显示一行。切换后 usage-dash 自动重新加载 |
| 额度提醒 | 剩余低于 10% ~ 40% | 全局提醒线；单个数据源可在数据源页另设 |
| 刷新频率 | 每 1 / 2 / 5 / 10 / 30 分钟 | 多久重读一次各平台。Claude 额度每次回复后都会更新，不受这项影响 |
| 没配好的数据源 | 横条里隐藏 / 横条里也显示 | 缺环境变量、或还没有读数的数据源 |

在手机 App 上，下拉框会换成一排按钮，当前选中的高亮。

最底下一行写着配置文件的位置。

## 4. 命令

| 命令 | 作用 |
| --- | --- |
| `/usage-dash` | 打开设置面板（没有地方放面板时改为列出数据源） |
| `/usage-dash list` | 刷新并列出所有数据源，包括未配置和已停用的 |
| `/usage-dash types` | 能加哪些类型、各自显示什么、需要准备什么 |
| `/usage-dash add <类型> [id]` | 按模板添加一个数据源；不写 id 时用类型名，重复就自动编号（`deepseek2`） |
| `/usage-dash disable <id>` | 停用 |
| `/usage-dash enable <id>` | 启用 |
| `/usage-dash remove <id>` | 删除 |
| `/usage-dash path` | 显示配置文件位置 |

## 5. 让 Claude 帮你改

直接用自然语言说，Claude 会调用 `usage_config` 工具，例如：

- “把 Codex 停掉”
- “DeepSeek 余额低于 10 就提醒我”
- “提醒线改成 25%”
- “加一个 http-json 数据源，接口是……，key 在环境变量 MINIMAX_API_KEY 里”
- “横条改成只在状态栏显示”
- “usage-dash 的配置恢复默认”（会先把原文件备份成 `.bak`）

每次保存前都会完整校验，不合法就整次不写，并告诉你哪里不对。

## 6. 配置各平台

| 类型 | 需要准备 |
| --- | --- |
| `claude` | 用 Claude 订阅登录 Claude Code 即可。第一次回复后才有读数 |
| `codex` | PATH 上有 `node` 和 `codex`，且 codex 已登录 |
| `agnes-plan` | 环境变量 `AGNES_EMAIL` 和 `AGNES_PASSWORD`（自动登录），或 `AGNES_PLATFORM_TOKEN` |
| `deepseek` | 环境变量 `DEEPSEEK_API_KEY`；余额阈值 `warnBalance` 默认 5，设 0 关闭 |
| `openai-billing` | 中转站地址 `baseUrl` 和存 key 的环境变量名 `keyEnv` |
| `http-json` | 接口 `url`，需要鉴权时写 `auth.env`；字段路径写法见 README |

**设置环境变量**：

- macOS / Linux：写进 shell 配置（如 `~/.zshrc`）里 `export DEEPSEEK_API_KEY=...`，然后重开终端。
- Windows：系统设置 → 环境变量 → 用户变量里新建。usage-dash 会直接读注册表里的用户变量，设好后下一次刷新就能读到，不用重启。

**注意**：配置里 `keyEnv`、`auth.env` 等字段写的是**环境变量的名字**（如 `MY_API_KEY`），不是 key 本身。把 key 填进去会被校验拦下。

## 7. 常见问题

**Claude 的额度不是实时的？**
是的。Claude Code 只在回复时从接口拿到额度，没有单独的查询接口。你在网页或别的设备上用掉的额度，要等任意一个会话下一次回复后才会显示。超过 5 分钟的读数会标注“N 分钟前”。

**横条没出现？**
- 新会话会先显示上一个会话的读数，所以一般一打开就有。从没读到过数据时，要等第一个数据源读完。
- 看看显示位置是不是被设成了“状态栏”或“不显示”（设置面板 → 显示与提醒）。
- 所有数据源都没配好且“没配好的数据源”设为隐藏时，横条里没有东西可显示。
- 本地安装的插件改过代码但没更新安装时，新会话还在用旧版本，见第 1 节。

**某个平台显示“未配置”？**
在设置面板的数据源页看它缺什么，通常是缺环境变量，设好后下一次刷新就会出现。

**配置文件改坏了？**
文件不是合法 JSON 时，面板、命令和 Claude 都不会改它，也不会用默认配置覆盖，会提示你先手动修好。也可以让 Claude 恢复默认，原文件会备份成 `.bak`。

**窗口很窄时按钮跑到了第二行？**
这是有意的：放不下时按钮换行，不会被挤出边界。把窗口拉宽就会回到一行。
